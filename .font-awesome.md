# Font Awesome Configuration

Detected by the Font Awesome agent tools. Commit this file so the whole team benefits.

## Integration

- **Method:** Kit embed (JS loader). The Kit's technology is set to Web Fonts (`method: css`), so icons are `<i>` elements and each glyph is the `::before` content.
- **Version:** 7.3.1
- **License:** Pro. The licence is Continia's. This public repo ships **no** Font Awesome files: the icons come from the Kit at runtime.
- **Kit ID:** `c11880975e` ("Continia Icons 2026", shared with the Continia Brand Hub). Use it as `--kit-token` with the `fa` CLI, for example `fa kit icon <name> --kit-token c11880975e`. The ID is an embed token, not a secret.
- **Kit Revision:** unknown here. The `fa` CLI is installed but was not logged in during setup, so the revision and the Kit's subset could not be read. Coverage was checked in a browser instead (see Conventions).
- **Embed:** `<script src="https://kit.fontawesome.com/c11880975e.js" crossorigin="anonymous"></script>` in the `<head>` of `index.html`
- **Families:** classic (solid, regular, light) plus Continia custom icons under `fa-kit`. No brands, duotone, sharp or thin.

## Defaults

- **Style:** light
- **Family:** classic

## Import Pattern

This is a static HTML site with no build step.

- Markup: `<i class="fa-light fa-xmark" aria-hidden="true"></i>`
- Built in JS (`src/listview.js`): create an `<i>`, set `className = 'fa-light fa-play'` and `aria-hidden="true"`.
- In WebGL (`src/main.js`, `iconGlyph()` / `makeBadgeTexture()`): the 3D video cards draw `fa-light fa-play` into a canvas texture. The code reads the glyph and font family from a hidden `<i>`'s `::before` and waits for the font, so the codepoint is never hard-coded.
- Size icons with `font-size` on `.fa-light` inside the control, for example `.btn .fa-light { font-size: 18px; }`.

## Conventions

These follow the Continia icon rules from the Brand Hub.

- **Classic light only.** Never regular, even though the Kit includes it. No duotone, sharp, thin, hand-drawn SVG icons, other icon libraries or emoji.
- **Colors:** on the Tech Blue ground, icons are White or Innovation Blue. On white menus, use Tech Blue.
- Decorative icons get `aria-hidden="true"`. Icon-only buttons carry an `aria-label`. Touch targets are at least 44 × 44 px.
- **In use:** `plus`, `images`, `clapperboard-play`, `solar-system` (Orbit view), `grid-2` (List view), `crosshairs`, `xmark`, `chevron-left`, `chevron-right`, `chevron-down`, `play`. A browser check confirmed every one of them renders from the Kit.
- **Not in the Kit:** `orbit` renders nothing. `solar-system` is used for the Orbit switch instead. To use `orbit`, add it to the Kit at https://fontawesome.com/kits first.
- **Domain restriction** is off on the Kit. If it is switched on, `anchcontinia.github.io` and `localhost` must be on the allowlist, or every icon on this site disappears.
